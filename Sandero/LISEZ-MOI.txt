SANDERO DASHBOARD - projet Android (APK + mode interface)
==========================================================

Ce dossier contient l'application Android complète. Il n'y a RIEN à programmer :
il faut seulement le "compiler" pour obtenir le fichier .apk.

---------------------------------------------------------------
OPTION 1 (la plus simple, sans rien installer) : GitHub
---------------------------------------------------------------
1. Crée un compte gratuit sur https://github.com
2. Clique sur "+" (en haut à droite) > "New repository". Nom : sandero-dashboard.
   Choisis "Private" (le dépôt contient ta clé de signature sandero.jks),
   puis "Create repository".
3. Clique sur "uploading an existing file", puis glisse-dépose TOUT le contenu de ce
   dossier (app, build.gradle, settings.gradle, gradle.properties, build.yml, ...).
   Clique "Commit changes".
4. IMPORTANT : GitHub ignore parfois le dossier caché ".github".
   Pour être sûr : "Add file" > "Create new file", dans le nom tape exactement
       .github/workflows/build.yml
   puis colle le contenu du fichier build.yml de ce dossier. "Commit changes".
5. Onglet "Actions" : la compilation démarre toute seule (sinon : "Build APK" >
   "Run workflow"). Attends 4 à 6 minutes, une coche verte apparaît.
6. Clique sur la compilation terminée, en bas "Artifacts" : télécharge
   "sandero-dashboard-apk" (un zip qui contient app-debug.apk).

CLÉ DE SIGNATURE (app/sandero.jks)
Le fichier app/sandero.jks signe toujours l'APK avec la même clé : tu peux installer
chaque nouvelle version PAR-DESSUS l'ancienne, sans perdre tes trajets ni tes réglages.
Garde ce fichier précieusement et ne le remplace jamais.
Si une ancienne version est déjà installée (signée sans cette clé), Android dira
"Application non installée" : désinstalle-la une seule fois, puis installe la nouvelle.

Si la compilation affiche une croix rouge : ouvre-la, copie le message d'erreur
et envoie-le moi, je corrige.

---------------------------------------------------------------
OPTION 2 : Android Studio (sur ordinateur)
---------------------------------------------------------------
1. Installe Android Studio (gratuit) : https://developer.android.com/studio
2. File > Open > choisis ce dossier. Attends la synchronisation.
3. Menu Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. Clique sur "locate" : app-debug.apk est dans app/build/outputs/apk/debug/.

---------------------------------------------------------------
INSTALLER SUR L'AUTORADIO / LA TABLETTE
---------------------------------------------------------------
1. Copie app-debug.apk sur une clé USB (ou envoie-le par Drive).
2. Sur l'appareil, ouvre un gestionnaire de fichiers, touche l'APK.
3. Si Android refuse : autorise "Sources inconnues" pour le gestionnaire de fichiers.
4. Ouvre "Sandero Dashboard". Au premier "Adaptateur OBD-II", accepte les autorisations
   Bluetooth (et la localisation sur Android 11 ou plus ancien : c'est Android qui
   l'exige pour chercher en Bluetooth, rien n'est envoyé nulle part).

MODE INTERFACE (écran d'accueil)
1. Appuie sur la touche Accueil de l'appareil.
2. Android demande quelle application d'accueil utiliser : choisis "Sandero Dashboard"
   puis "Toujours". (Sinon : Réglages > Applications > Applications par défaut >
   Accueil.)
3. Pour revenir à l'ancien écran d'accueil : même endroit, choisis l'ancien.

ATTENTION sur autoradio Android chinois : le launcher d'origine gère la radio, la
climatisation, la caméra de recul, les boutons au volant... Mets d'abord l'application
sans la définir par défaut, ouvre-la depuis la liste des applications, et vérifie.
Dans le menu de l'accueil (bouton à 4 carrés) > "Toutes les applications" : tu peux
lancer n'importe quelle application et l'ajouter à l'accueil avec "+".

BLUETOOTH OBD
- Les ELM327 Bluetooth LE (4.0) : choisis-les dans la liste.
- Les ELM327 Bluetooth classique : appaire-les d'abord dans les réglages Bluetooth
  d'Android (code 1234 ou 0000), ils apparaissent alors dans la liste "appairé".

---------------------------------------------------------------
APPLI IPHONE (dossier iphone/)
---------------------------------------------------------------
1. Sur GitHub, crée un 2e dépôt, PUBLIC cette fois : sandero-iphone.
2. Envoie-y les 5 fichiers du dossier iphone/ : index.html, car3d.js, car.bin,
   icon.png, manifest.webmanifest.
3. Settings > Pages > Branch : main > Save. Adresse : ton-pseudo.github.io/sandero-iphone
4. Sur l'autoradio : Réglages > "Adresse de l'appli iPhone" > colle l'adresse.
5. Sur l'iPhone : ouvre l'adresse dans Safari > Partager > "Sur l'écran d'accueil".
6. Synchro : écran Trajets de l'autoradio > "Envoyer vers l'iPhone", puis
   "Scanner le QR de l'autoradio" dans l'appli iPhone.

GPS (facultatif) : dans Trajets > Trajets favoris, "Activer le GPS" permet de mieux
reconnaître tes trajets habituels. La position reste dans l'appli.

Modèle 3D : Dacia Sandero 1.2 16V (fichier fourni, converti pour l’appli).
